# 🕸 PRODIGY_SD_05 – Web Scraper

A modern Web Scraper built using Python, BeautifulSoup, Pandas, and CustomTkinter. The application extracts product information such as names, prices, and ratings from a website and stores the data in a CSV file.

---

## 🚀 Features

- 🌐 Web Scraping using BeautifulSoup
- 📖 Extract Product Information
- 💲 Extract Prices
- ⭐ Extract Ratings
- 📁 Automatic CSV Export
- 🌙 Modern Dark-Themed GUI
- ⚡ Fast and Interactive Interface

---

## 🛠 Technologies Used

- Python
- BeautifulSoup
- Requests
- Pandas
- CustomTkinter

---

## ▶ How to Run

### 1️⃣ Install Required Libraries

```bash
pip install requests beautifulsoup4 pandas customtkinter
```

### 2️⃣ Run the Program

```bash
python web_scraper.py
```
